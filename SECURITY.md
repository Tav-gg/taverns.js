# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to **security@tav.gg**. Do not open a public GitHub
issue for them.

Include what you found, the version of taverns.js, and the steps to reproduce it if you can. We will
confirm that we received your report, keep you updated while we work on a fix, and credit you in the
release notes if you would like.

If you think a bot token or webhook secret has been exposed, regenerate it in the Taverns developer
portal straight away.

## Supported versions

Security fixes are made in the latest released version. Please upgrade to it before reporting.
